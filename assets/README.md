# 聆境音乐品牌素材

app-icon.png：用户选择A方案的正式高光位图，保留原始方案。
app-icon.svg：可编辑矢量重绘版本；保留云朵、音符和渐变，不含嵌入位图，光学细节与生成位图不同。
lingjing-logo.svg：去除方形底板的透明矢量标志。

lingjing-logo-transparent.png：去除最外层矩形底板的透明正式标志，用于启动页和首页右上角。

lingjing-icon-tile.png：保留内层圆角玻璃底板，去掉外层背景，用于常规桌面图标。
lingjing-tv-banner.png：16:9 电视桌面横版图标，用于 Android TV banner。

手机 Android 8+ 使用自适应图标：不透明纯白色（#FFFFFF）底板铺满系统形状，云朵音符作为前景。旧系统图标裁掉源图外侧留白；电视继续使用横版 banner。
